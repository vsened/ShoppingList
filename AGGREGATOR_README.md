# 🌍 Multiplatform Project Aggregator (KMP / Android / iOS)

Универсальный инструмент на Python для подготовки контекста многоплатформенных проектов. Скрипт собирает код из Kotlin Multiplatform, Android и iOS модулей, очищает его от мусора и подготавливает для анализа в LLM (ChatGPT, Gemini, Claude).

---

## ✨ Основные возможности

- **Поддержка KMP & iOS**: Понимает специфику Swift, Objective-C, Kotlin (Common/Native) и конфигурационных файлов (Podfile, Package.swift).
- **Умная приоритизация**:
    1. Конфиги и зависимости (toml, build.gradle, Podfile).
    2. Бизнес-логика (Kotlin, Swift, Java).
    3. Ресурсы и верстка (XML).
- **Максимальная экономия токенов**:
    - **Глубокая очистка**: Удаляет комментарии (однострочные и многострочные) из Swift, Kotlin, Java и XML.
    - **Фильтрация тяжелых ресурсов**: Пропускает векторную графику, Storyboards, XIB и Asset-каталоги.
    - **Черный список**: Игнорирует системные папки (.git, .xcodeproj, DerivedData, Pods, build).
- **Устойчивая структура**: Дерево проекта с символами |-- сохраняет иерархию даже при копировании в веб-интерфейсы чат-ботов.

---

## 🚀 Инструкция по использованию

### 1. Подготовка
Разместите файл aggregator.py в корне вашего репозитория.

### 2. Примеры команд

**Для обычного Android или iOS проекта:**
python aggregator.py . -o project_context

**Для большого KMP проекта (разбивка по 600 КБ):**
python aggregator.py . --split --max-size 600 -o kmp_context

**Запуск из другой папки для конкретного проекта:**
python aggregator.py /path/to/project -o my_context --split

---

## ⚙️ Параметры командной строки

| Флаг            | Описание                                      | По умолчанию        |
| :-------------- | :-------------------------------------------- | :------------------ |
| path            | Путь к папке проекта (позиционный).           | .                   |
| -o, --output    | Имя выходного файла (без .md).                | multiplatform_context |
| --split         | Включить разбивку на несколько файлов.        | Выключено           |
| --max-size      | Максимальный размер одной части в КБ.         | 600                 |

## 📂 Что фильтрует скрипт?

- **Android**: build/, .gradle/, local.properties, ExampleTests.
- **iOS/Apple**: .xcodeproj/, .xcworkspace/, DerivedData/, Pods/, .swiftpm/, Podfile.lock.
- **Общее**: .git/, .idea/, node_modules/, LICENSE, README.md, .DS_Store.
- **Контент**: Комментарии кода и тяжелые XML/Storyboard данные.
